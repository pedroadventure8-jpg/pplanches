# Sistema de Comandas PP Lanches (58mm)

Aplicação desenvolvida em Python/Streamlit para a Pastelaria e Pizzaria PP Lanches.

## Funcionalidades
- Cardápio completo de Pastéis (P/G) e Pizzas (P4, M8, G10, GG12 com bordas recheadas).
- Seção flexível de Bebidas.
- Impressão térmica de 58mm otimizada.
- Histórico de vendas salvo automaticamente em memória e com suporte nativo para conexão com **Google Sheets**.

## Como Rodar Localmente
1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Execute a aplicação:
   ```bash
   streamlit run app.py
   ```
