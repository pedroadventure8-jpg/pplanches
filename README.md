# 🧾 Sistema Gerador de Comandas - PP Lanches

Este repositório contém o sistema completo de emissão de comandas para impressão térmica de **58mm** da **Pastelaria e Pizzaria PP Lanches**.

## 🚀 Como publicar este site ONLINE gratuitamente em 3 minutos:

1. **Crie um Repositório no GitHub**:
   - Vá para [github.com](https://github.com) e faça login.
   - Clique em **New Repository** (Novo Repositório).
   - Nomeie como `comandas-pp-lanches`.
   - Clique em **Create repository**.
   - Faça o upload dos arquivos `app.py` e `requirements.txt` diretamente no repositório criado.

2. **Publicar no Streamlit Community Cloud**:
   - Acesse [share.streamlit.io](https://share.streamlit.io/) e faça login com sua conta do GitHub.
   - Clique em **New app** (Novo aplicativo).
   - Selecione o repositório `comandas-pp-lanches` e o arquivo principal `app.py`.
   - Clique em **Deploy!**.

Pronto! Em poucos segundos seu site estará online 24h por dia para acessar pelo celular, tablet ou computador do caixa!
